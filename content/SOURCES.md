# Источники контента

**Статус лицензии всех источников: не подтверждена.** PDF лежат в `content/sources/` и в git не попадают. Репозиторий и сайт публичные, поэтому из книг берём только отдельные слова и короткие бытовые фразы, а упражнения, тексты и диалоги не копируем.

Все единицы хранят `verified: false`. Сверка с носителем — в конце проекта, через `content/review/units.csv`. В первую очередь проверяем `source: translator`.

## Лицензии: что сделать до широкого распространения

| Источник | Статус | Что нужно |
|---|---|---|
| Учебник Burlang.Nom (`bxr-textbook`) | не подтверждена | Письмо в Burlang (buryat-lang.ru): разрешение на слова, короткие предложения и правила с указанием источника |
| Разговорник Burlang.Zugaa | не подтверждена | То же письмо: реплики темы «Приветствие» |
| «Тематический словарь» (`temslov`) | не подтверждена | Найти издателя (выходные данные в PDF), запросить разрешение на слова |
| Аудиоуроки радио «Буряад FM» | автор проекта дал согласие на использование; права радио не подтверждены | Письмо в «Буряад FM»: разрешение на клипы слов и полные уроки в приложении с указанием радио |
| Детский аудиокурс | автор проекта дал согласие на использование; правообладатель не установлен | Установить автора курса и исполнителей песен |
| Звуки интерфейса UI SFX | CC0 | Ничего |
| Машинный перевод (`translator`) | ограничений нет | Сверка с носителем — список `npm run review:priority` |

До ответов правообладателей приложение остаётся некоммерческим, у каждой единицы указан источник.

## Что проверить первым

```bash
npm run review:priority
```

Создаёт `content/review/priority.csv`: машинный перевод, реплики диалогов, записи, при которых распознавание сомневалось, черновые переводы предложений и подозрения на опечатку. Внутри каждого уровня сначала то, что видно в уроках. Правки вносятся через `units.csv` (`npm run review:export` / `review:import`).

Сканы без текстового слоя читаются только глазами, скриптом их не разобрать. Описания составлены по обложкам и выборочным страницам.

| `Toli.pdf` | Школьный бурятско-русский и русско-бурятский словарь | скан | Сверка и поиск слов (часы, кровать, автобус) |
