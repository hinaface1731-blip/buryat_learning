# Бурятский язык — MVP

Приложение для изучения литературного бурятского языка с нуля по механике Duolingo: короткие уроки, серия дней, интервальные повторения. Аудитория — русскоязычные взрослые, интерфейс на русском.

Работает только в **Expo Go** (без dev client, EAS и нативных модулей). Всё хранится локально: нет бэкенда, аккаунтов, аналитики и трекеров.

> **Главное правило контента.** Бурятские слова, формы и переводы берутся только из источников (`content/SOURCES.md`) или от носителя. В коде ничего не сочиняется и не «исправляется». Любая единица хранит `verified: false`, пока её не подтвердит носитель. В dev-сборке на непроверенных единицах видна пометка «не проверено носителем», в релизе — по настройке в профиле.

## Запуск на iPhone через Expo Go

1. Установите Node.js 20+ и [Expo Go](https://apps.apple.com/app/expo-go/id982107779) на iPhone. Нужен Expo Go с поддержкой **SDK 58**.
2. В папке проекта:
   ```bash
   npm install
   ```
   ```bash
   npx expo start
   ```
3. Отсканируйте QR-код камерой iPhone. Телефон и компьютер должны быть в одной Wi-Fi-сети. Если сеть не позволяет:
   ```bash
   npx expo start --tunnel
   ```

Чек-лист ручной проверки на устройстве:
- онбординг → выбор цели;
- «Путь» → урок юнита «Звуки һ, ү, өө, н»: карточка «Что нужно знать», знакомство, выбор, сопоставление, ввод с панелью Ү ү Ө ө Һ һ над клавиатурой;
- итог урока: точность, XP, ошибки;
- «Повторение» (ошибки доступны сразу);
- «Словарь»: поиск «хургуули» находит «һургуули»;
- «Профиль»: тёмная тема, сердечки, сброс прогресса;
- хаптика на ответах.

## Веб-версия

Тот же код, тот же контент. Прогресс хранится в `localStorage` браузера.

Разработка с горячей перезагрузкой:

```bash
npm run web
```

Сборка статического сайта в `dist/` — отдельная HTML-страница на каждый экран и урок, подходит для любого статического хостинга:

```bash
npm run build:web
```

Локальная проверка собранного сайта (http://localhost:8081):

```bash
npm run serve:web
```

Отличия от приложения:
- на широком экране — центральная колонка шириной до 640 px;
- клавиши: 1–4 — выбор ответа, Enter — «Проверить» в поле ввода и «Дальше», Esc — выйти из урока;
- панель Ү ү Ө ө Һ һ — строкой под полем ввода, а не над клавиатурой;
- без вибрации;
- можно установить как приложение (PWA): `public/manifest.json`, иконки `public/icon-*.png`.

> Перед публичной публикацией: лицензия учебника не подтверждена (см. `content/SOURCES.md`), а слова из него попадают в собранный сайт.

## Курс (MVP)

| Юнит | Источник |
|---|---|
| 1. Алфавит и особые буквы Ү Ө Һ | учебник, стр. 1–2 |
| 2. Звуки һ, ү, өө, н | урок 1 учебника |
| 3. Йотированные гласные | урок 2 + §5, §8б введения |
| 4. Краткие/долгие гласные, минимальные пары | урок 3 + §7–8 введения |
| 5. Дифтонги | урок 4 + §9 введения |
| Тематические (Знакомство, Семья, Числа, …) | закрыты, ждут слов от носителя |

Урок построен по схеме «знакомство → тренировка → применение → контроль» и рассчитан на 5–7 минут.

Упражнения:
- выбор перевода;
- сопоставление пар;
- ввод;
- минимальные пары;
- прослушивание — только если есть запись;
- ряды гласных;
- сборка предложения — только если у предложения есть перевод.

### Проверка ответов

Регистр, пробелы и знаки препинания не важны.

«Почти верно» засчитывается, если особые буквы заменены (ү→у, ө→о, һ→х) **и** получившееся слово не является другим словом курса. Например, «хун» вместо «хүн» — неверно. В минимальных парах допуска нет. Логика описана в `src/engine/check.ts`, тесты — в `src/engine/__tests__/check.test.ts`.

## Как править контент

Источники лежат в `content/sources/` и в git не попадают (см. `content/SOURCES.md`).

```
content/
  words.json  sentences.json  minimal-pairs.json   генерируются импортом, правятся через CSV
  alphabet.json  vowel-rows.json  notes.json         внесены вручную по страницам учебника
  course.json                                        раскладка по юнитам и урокам (генерируется)
  review/units.csv                                   выгрузка для сверки
  templates/thematic-words.csv                       шаблон для слов носителя
```

### Сверка с носителем

```bash
npm run review:export
```

Создаёт `content/review/units.csv`. Откройте его в Excel или Google Таблицах. Редактируемые колонки:
- `buryat`, `russian`;
- `alternatives` — через « | »;
- `form` — `lemma` или `form`;
- `translation` — для предложений;
- `excluded`, `verified` (да/нет), `comment`.

Колонки `book_text`, `review_reasons`, `typo_candidates` — справочные: в них текст книги и причина пометки.

```bash
npm run review:import
```

Это предпросмотр: показывает изменения и ошибки, ничего не записывает.

```bash
npm run review:import -- --apply
```

Записывает изменения и пересобирает курс. Подтверждённые слова попадают в уроки. Слова с подозрением на опечатку (`possible_typo`) и служебные пометки в уроки не попадают, пока их не проверят.

Повторный импорт учебника правки не теряет. Слияние идёт по исходной строке книги, id не меняются.

```bash
npm run import:textbook
```

### Слова носителя для тематических юнитов

Заполните `content/templates/thematic-words.csv`:
- колонки: `unit` (например «Семья»), `buryat`, `russian`, `alternatives`, `comment`, `speaker`.

```bash
npm run review:import -- --thematic --apply
```

Юнит откроется автоматически.

### Отчёт о состоянии

```bash
npm run validate:content
```

Показывает, сколько единиц не верифицировано, без аудио, с `needs_review`, без перевода. Падает, если контент не проходит схемы или в нём есть битые ссылки.

## Как добавить аудио

TTS не используется, только записи носителя.

1. Список слов по приоритету (Ү, Ө, Һ → долгие гласные → минимальные пары):
   ```bash
   npm run audio:checklist
   ```
   Результат — `content/review/audio-checklist.csv`.
2. Сохраните запись как `assets/audio/{id}.m4a`. id и имя файла — в колонке `file`.
3. Пересоберите индекс: Metro требует статические `require`.
   ```bash
   npm run audio:index
   ```

После этого появятся кнопка прослушивания и упражнение «Что вы слышите?».

## Разработка

```bash
npm run check
```

Запускает typecheck, eslint и jest.

- `src/app/` — экраны (expo-router);
- `src/engine/` — упражнения, проверка ответов, сессия;
- `src/srs/` — упрощённый SM-2;
- `src/store/` — zustand + AsyncStorage;
- `src/content/` — zod-схемы и загрузчик;
- `scripts/` — импорт, CSV, валидация, аудио.
